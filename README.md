# Higher or Lower

A small browser game where you guess the computer’s number from 1 to 100.

## Play

Open `index.html` in a browser, enter a whole number, and submit your guess. You get up to three guesses with higher/lower hints. If you miss all three, the game reveals the answer. Choose **Start over** for a new number.

The game uses plain HTML, CSS, and JavaScript. No installation or dependencies are needed.
